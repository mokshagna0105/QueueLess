# Queueless

## Application Description
Queueless is a virtual queue management application that allows users to join queues remotely at clinics, restaurants, salons, and other public service locations. Users can view their queue position, track the number of people ahead of them, check estimated waiting times, and receive notifications when their turn is approaching.

## Selected Feature: View Live Queue Status

### Description
This feature allows users who have joined a virtual queue to monitor their queue status in real time. Users can view their token number, current position, number of people ahead, estimated waiting time, and booking status.

### Benefits
- Reduces the need to wait in physical queues.
- Helps users plan when to arrive at a service location.
- Improves convenience and customer experience.
- Provides transparent queue progress information.

## Target Users
- Patients visiting clinics
- Customers at restaurants
- Customers at salons
- People accessing other public services

## Key Features
- Search for nearby service locations
- Join virtual queues
- View live queue status
- Receive turn notifications
- Cancel queue bookings
- View active and past bookings
